The independent SceneQuarry version sequence begins at 0.1.0. Earlier 2.x version numbers in dated evidence describe inherited checkpoints; they are not SceneQuarry releases or validation of the current revision.

For compatibility, the internal Python package `scripts/getbrolls/`, the `scripts/gb.py` launcher, `GB_*`/`GETBROLLS_*` variables, `~/.getbrolls`, the `brolls/` project tree and existing JSON/schema keys retain their established spellings. These are storage and interface identifiers, not the public skill or plugin name. Existing projects need no data migration.
